# PortraitsByHope
Website for Hope's Art

## Deployment

- Hosted with GitHub Pages from this repository's `main` branch.
- Live site URL: https://jcr422003-lab.github.io/PortraitsByHope/
- Site is static HTML (files: `index.html`, `images/`), so Pages serves files directly.

## Local preview

1. Open `index.html` in a browser, or run a simple HTTP server in the project folder:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

Alternatively use the VS Code Live Server extension to preview changes.

## Updating the site

- Edit the HTML/CSS files, commit, and push to the `main` branch. GitHub Pages will publish updates automatically (usually within a few minutes).

## Notes

- This repo contains the static site files only. If you want a CI/CD or custom domain, we can add configuration.
